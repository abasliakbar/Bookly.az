Build a SaaS project called "Bookly" (bookly.az) for the Azerbaijani market.
It is an online appointment management system for small businesses 
(barbershops, beauty salons, dentists, massage therapists, fitness coaches).

## BRAND
- Name: Bookly
- Domain: bookly.az
- Tagline: "Onlayn randevu, asan idarəetmə"
- Primary color: #059669 (emerald green)
- Secondary: #FFFFFF (white), #0F172A (dark navy)
- Logo: Minimal calendar icon + "Bookly" wordmark
- Tone: Professional, friendly, local (Azerbaijani-first)

## TECH STACK
- Frontend: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- Backend: Next.js API routes
- Database: PostgreSQL (Replit built-in DB) + Prisma ORM
- Auth: NextAuth.js (email + Google OAuth)
- Payments: Lemon Squeezy (subscription, supports Azerbaijan)
- Email: Resend (for confirmations & reminders)
- Deployment: Replit

## LEMON SQUEEZY INTEGRATION
- Create /api/checkout route — generates Lemon Squeezy checkout URL
- Webhook endpoint: /api/webhooks/lemon-squeezy
  * subscription_created → user plan = active
  * subscription_updated → update plan
  * subscription_cancelled → plan = free
- MUST verify webhook signature (HMAC)
- Store variant IDs in .env:
  * LEMON_PRO_VARIANT_ID
  * LEMON_BUSINESS_VARIANT_ID
  * LEMON_API_KEY
  * LEMON_WEBHOOK_SECRET
  * LEMON_STORE_ID
